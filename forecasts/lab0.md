# Предварительный прогноз для ЛР0

1. Ожидаю, что разница между максимальной и минимальной точностью на val для базовой модели с seed 1–5 составит примерно 0,5–1,5 процентного пункта. Причина — разные начальные веса и порядок обучающих примеров.

2. Ожидаю, что лучший trial Optuna превзойдёт базовую конфигурацию с seed 0 на val примерно на 0,5–1,5 процентного пункта.

3. При обучении с новыми seed ожидаю меньшего преимущества. Средний прирост на test предполагаю в пределах 0–1 процентного пункта; отдельные разности могут быть нулевыми или отрицательными. Часть преимущества лучшего trial может объясняться подбором под val.

Это предположения до основных экспериментов. После запусков сравню их с фактическими результатами.
