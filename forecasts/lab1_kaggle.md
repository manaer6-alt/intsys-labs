# Прогноз повторной серии ЛР1 на Kaggle

Это повторная серия после предварительных опытов Colab, а не прогноз без знания результатов. Исходный прогноз Colab сохраняется отдельно.

На одной T4 ожидаем роста TTFT с длиной запроса; на длинных входах рост может быть быстрее линейного. В Colab медианы TTFT были примерно 0,17; 0,81; 8,31; 30,19 и 114,17 с для 256–16384 токенов. Эти значения являются ориентирами, а не результатами Kaggle.

Ожидаем значительного уменьшения TTFT при втором и третьем полностью одинаковом запросе с кешированием префикса. В Colab наблюдалось такое ускорение; полные файлы того опыта необходимо проверять отдельно.

Для ответов 16–1024 токена при входе 1024 токена ожидаем приблизительно линейного роста полного времени. Ориентир TPOT по Colab — около 60 мс, однако он может меняться с длиной контекста и средой.

Для нагрузки заранее сохраняем критерии: p90 TTFT <= 2 с и медиана TPOT <= 0,1 с. Goodput считаем по отдельным запросам, выполнившим оба соответствующих порога. Предполагаем нарушение хотя бы одного критерия на уровне 16 или 32 клиента; это не расчёт и не установленный факт.

Код и прогноз подготовлены с ИИ-помощником. После начала серии прогноз не редактируем. Не выбираем результаты по величине метрик; ошибки и повторные серии сохраняем отдельно.
