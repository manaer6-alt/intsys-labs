# Прогноз ЛР3 до экспериментов

- Ожидаю, что BM25 найдёт часть свидетельств, которые пропустил Dense, особенно при точных совпадениях редких обозначений. Кандидат для проверки — ID 70 с терминами PPM1D и p53. Dense может оказаться сильнее для перефразированных утверждений.
- Ожидаю, что RRF сохранит часть уникальных находок обоих методов, но может опустить документ, который высоко поставил только один из них. Проверю это по группам дополнительности и вкладам по рангам.
- Ожидаю, что cross-encoder улучшит порядок первой тройки хотя бы для отдельных утверждений, не меняя Recall@20. Улучшение Accuracy не гарантировано: важное предложение ещё должно попасть в контекст, а Qwen должна правильно его использовать.

## Правило выбора до holdout

Среди BM25, RRF и RRF + CE выбираем максимальный MRR@3 на dev. При равенстве — максимальный Recall@3, затем более простой метод в порядке BM25, RRF, RRF + CE. До запуска holdout записываем выбранный вариант, метрики dev, коммит и хеш конфигурации в selection.json. После просмотра holdout выбор и параметры не меняем.
